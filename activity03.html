Activity 3: Paper Airplane

For this project, we were tasked with using a generative AI chatbot to create a paper airplane. Absolutely no decisions about the creation of the plane wee to be made by me. I was only permitted to ask clarifying questions where necessary. These were frequent since the chatbot (ChatGPT) kept trying to create ASCII art to represent the state of the plane, but it would completely different from how the plane looked.
